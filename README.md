# biopalette

A story-driven palette collection for biomedical visualization.

Each palette in **biopalette** begins with a figure —
from scientific imagery, films, artworks, or editorial graphics —
and is translated into a reproducible color system for use in R.

## Philosophy

biopalette is built on a simple workflow:

1. Start from a compelling figure
2. Extract the visual color relationships
3. Translate into a usable palette
4. Test in common biomedical plots (UMAP, forest, heatmap, etc.)
5. Document the source, style, and recommended use

The goal is not to collect colors, but to build
a **context-aware palette system** for scientific visualization.
