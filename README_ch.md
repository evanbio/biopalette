# biopalette

一个面向生物医学可视化的故事驱动调色板合集。

**biopalette** 中的每一套调色板都源自一张图像——
来自科学影像、电影、艺术作品或编辑设计——
并被转化为可在 R 中复用的标准化配色系统。

## 设计理念

biopalette 基于一套简洁的工作流程构建：

1. 从一张引人入胜的图像出发
2. 提取其视觉色彩关系
3. 转化为可用的调色板
4. 在常见生物医学图表中测试（UMAP、森林图、热图等）
5. 记录来源、风格与推荐用途

目标不是单纯地收集颜色，而是为科学可视化构建一套
**具有情境感知能力的配色系统**。
