# Historical 0.2.1 release

The 0.2.1 release fixed CRAN DESCRIPTION wording by quoting the software name
'ggplot2' and compressed the package logo without changing its dimensions.

# Historical 0.2.0 release

The 0.2.0 release redesigned palette storage, added ggplot2 scales, expanded
tests and Tessera/Palette Lab documentation, and introduced three B-cell atlas
palettes.

# Historical 0.1.0 release

The April 2026 initial release established the core palette retrieval, preview,
storage, color-conversion, and palette-management functions together with the
`gene_red`, `walter_white`, `walter_white2`, `walter_white3`, `babel`, and
`three_body` palettes.
